# Netwerken 3 - Volledige Lijst Afkortingen

## Netwerken & Protocollen

**LAN** - Local Area Network: Een netwerk binnen een beperkt gebied zoals een kantoor of school.

**WAN** - Wide Area Network: Een netwerk over een groot geografisch gebied dat meerdere LAN's verbindt.

**ADSL** - Asymmetric Digital Subscriber Line: Breedbandtechnologie over telefoonlijnen met meer download dan upload capaciteit.

**VDSL** - Very High Speed Digital Subscriber Line: Snellere variant van DSL met beperking tot 1 km afstand tot DSLAM.

**HDSL** - High bit rate Digital Subscriber Line: DSL variant die 2 paar telefoonkabels gebruikt.

**SDSL** - Symmetric Digital Subscriber Line: DSL met gelijke upload en download snelheid, gebruikt voor servers.

**DSLAM** - Digital Subscriber Line Access Multiplexer: Apparaat in straatkast dat DSL-verbindingen bundelt.

**NAT** - Network Address Translation: Techniek om interne IP-adressen te vertalen naar externe IP-adressen.

**NAPT** - Network Address Port Translation: Uitgebreide NAT die ook poortnummers bijhoudt voor meerdere verbindingen via één publiek IP.

**DNS** - Domain Name System: Systeem dat domeinnamen vertaalt naar IP-adressen.

**DHCP** - Dynamic Host Configuration Protocol: Protocol voor automatische toewijzing van IP-adressen aan apparaten.

**HTTP** - Hypertext Transfer Protocol: Protocol voor het overdragen van webpagina's.

**HTTPS** - HTTP Secure: Beveiligde versie van HTTP met encryptie.

**FTP** - File Transfer Protocol: Protocol voor het overdragen van bestanden.

**TCP** - Transmission Control Protocol: Betrouwbaar transportprotocol met verbindingsopzet en hertransmissie.

**UDP** - User Datagram Protocol: Onbetrouwbaar transportprotocol zonder verbindingsopzet, gebruikt voor snelheid.

**IP** - Internet Protocol: Protocol voor adressering en routering van pakketten over netwerken.

**IPv4** - Internet Protocol versie 4: Oudere IP-versie met 32-bit adressen.

**IPv6** - Internet Protocol versie 6: Nieuwe IP-versie met 128-bit adressen voor meer adresruimte.

**ICMP** - Internet Control Message Protocol: Protocol voor foutmeldingen en diagnostische berichten zoals ping.

**ICMPv6** - ICMP voor IPv6: Uitgebreide versie van ICMP met extra functies voor IPv6.

**ARP** - Address Resolution Protocol: Protocol om IP-adressen te vertalen naar MAC-adressen binnen een LAN.

**MAC** - Media Access Control: Uniek hardwareadres van een netwerkkaart (48-bit).

**PPP** - Point-to-Point Protocol: Protocol voor directe verbindingen tussen twee netwerkapparaten.

**SMTP** - Simple Mail Transfer Protocol: Protocol voor het verzenden van e-mail tussen servers.

**POP3** - Post Office Protocol versie 3: Protocol voor het ophalen van e-mail van een server.

**OSI** - Open Systems Interconnection: Referentiemodel met 7 lagen voor netwerkcommunicatie.

**QoS** - Quality of Service: Mechanismen om kwaliteit en prioriteit van netwerkverkeer te garanderen.

**TTL** - Time To Live: Veld dat aangeeft hoeveel hops een pakket mag maken voordat het verwijderd wordt.

**VPN** - Virtual Private Network: Beveiligde verbinding over een onveilig netwerk.

**VLAN** - Virtual Local Area Network: Logische segmentatie van een fysiek netwerk.

**ESS** - Extended Service Set: Meerdere access points die samen één draadloos netwerk vormen.

**SSID** - Service Set Identifier: Naam van een draadloos netwerk.

**ESSID** - Extended SSID: SSID gebruikt in infrastructure netwerken met access points.

## Routing & Switching

**BGP** - Border Gateway Protocol: Routing protocol tussen autonome systemen op het internet.

**OSPF** - Open Shortest Path First: Link-state routing protocol voor interne netwerken.

**RIP** - Routing Information Protocol: Distance-vector routing protocol voor kleinere netwerken.

**RIPv2** - RIP versie 2: Verbeterde versie van RIP met ondersteuning voor subnetting.

**EIGRP** - Enhanced Interior Gateway Routing Protocol: Cisco's geavanceerde distance-vector protocol.

**AS** - Autonomous System: Verzameling IP-netwerken beheerd door dezelfde organisatie met uniek ASN.

**ASN** - Autonomous System Number: Uniek nummer toegekend aan een autonoom systeem.

**IBGP** - Internal BGP: BGP gebruikt binnen een autonoom systeem.

**EBGP** - External BGP: BGP gebruikt tussen verschillende autonome systemen.

**CIDR** - Classless Inter-Domain Routing: Flexibele methode voor IP-adrestoewijzing zonder vaste klassen.

**VPI** - Virtual Path Identifier: Identificatie van virtueel pad in ATM netwerken.

**VCI** - Virtual Channel Identifier: Identificatie van virtueel kanaal binnen een ATM pad.

**VRRP** - Virtual Router Redundancy Protocol: Protocol voor failover tussen routers.

**ACL** - Access Control List: Lijst met regels voor toegangscontrole van netwerkverkeer.

**UNI** - User-Network Interface: Interface aan de rand van ATM netwerk.

**NNI** - Network-Network Interface: Interface binnen ATM netwerk tussen switches.

**LSR** - Label Switch Router: Router in het hart van een MPLS netwerk.

**LER** - Label Edge Router: Router aan de rand van een MPLS netwerk die labels toevoegt/verwijdert.

**LSP** - Label Switched Path: Vooraf vastgelegd pad in MPLS netwerk.

**STP** - Shielded Twisted Pair: Afgeschermde twisted pair kabel.

**UTP** - Unshielded Twisted Pair: Onafgeschermde twisted pair kabel.

## Draadloze Technologieën

**WLAN** - Wireless Local Area Network: Draadloos lokaal netwerk.

**WPAN** - Wireless Personal Area Network: Draadloos netwerk voor persoonlijk gebruik binnen korte afstand.

**WiFi** - Wireless Fidelity: Commerciële naam voor IEEE 802.11 draadloze standaarden.

**AP** - Access Point: Apparaat dat draadloze apparaten verbindt met een bekabeld netwerk.

**MIMO** - Multiple Input Multiple Output: Technologie met meerdere antennes voor hogere snelheden.

**OFDM** - Orthogonal Frequency Division Multiplexing: Modulatietechniek die bandbreedte opdeelt in subdragers.

**QAM** - Quadrature Amplitude Modulation: Modulatietechniek die amplitude en fase combineert.

**FHSS** - Frequency Hopping Spread Spectrum: Techniek waarbij frequentie constant wisselt.

**WEP** - Wired Equivalent Privacy: Oude, onveilige encryptiestandaard voor WiFi.

**WPA** - Wi-Fi Protected Access: Verbeterde WiFi-beveiliging ter vervanging van WEP.

**WPA2** - WPA versie 2: Tweede generatie WPA met AES-encryptie.

**WPA3** - WPA versie 3: Nieuwste WiFi-beveiligingsstandaard met verbeterde encryptie.

**TKIP** - Temporal Key Integrity Protocol: Encryptiemethode gebruikt in WPA.

**AES** - Advanced Encryption Standard: Moderne encryptiestandaard gebruikt in WPA2/WPA3.

**PSK** - Pre-Shared Key: Gedeelde sleutel voor authenticatie zonder centrale server.

**EAP** - Extensible Authentication Protocol: Framework voor authenticatiemethoden in netwerken.

**PEAP** - Protected EAP: EAP-methode met beveiligde TLS-tunnel.

**LEAP** - Lightweight EAP: Cisco's EAP-implementatie (inmiddels onveilig).

**TLS** - Transport Layer Security: Protocol voor beveiligde communicatie via encryptie.

**RADIUS** - Remote Authentication Dial-in User Service: Server voor centrale authenticatie en accounting.

**IAS** - Internet Authentication Service: Microsoft's implementatie van RADIUS.

**AAA** - Authentication, Authorization, Accounting: Model voor toegangscontrole en logging.

**MIC** - Message Integrity Check: Controlemechanisme om berichtintegriteit te verzekeren.

**CCMP** - Counter Mode CBC-MAC Protocol: Encryptieprotocol gebruikt in WPA2.

**MANET** - Mobile Ad-hoc Network: Zelfconfigurerende netwerk van mobiele apparaten zonder vaste infrastructuur.

## Modulatie & Transmissie

**AM** - Amplitude Modulation: Modulatietechniek waarbij amplitude varieert.

**FM** - Frequency Modulation: Modulatietechniek waarbij frequentie varieert.

**PM** - Phase Modulation: Modulatietechniek waarbij fase varieert.

**FDM** - Frequency Division Multiplexing: Opdeling van bandbreedte in verschillende frequentiegebieden.

**TDM** - Time Division Multiplexing: Opdeling waarbij apparaten om de beurt het kanaal gebruiken.

**STDM** - Statistical Time Division Multiplexing: Efficiëntere TDM door dynamische toewijzing.

**WDM** - Wavelength Division Multiplexing: Gebruik van verschillende golflengten in glasvezel.

**DWDM** - Dense WDM: WDM met veel kanalen (16+) voor hoge capaciteit.

**DMT** - Discrete Multi Tone: Modulatietechniek die bandbreedte opdeelt in subkanalen zoals bij ADSL.

**ASK** - Amplitude Shift Keying: Digitale modulatie door amplitude te variëren.

**FSK** - Frequency Shift Keying: Digitale modulatie door frequentie te variëren.

**PSK** - Phase Shift Keying: Digitale modulatie door fase te variëren.

**PCS** - Probabilistic Constellation Shaping: Geavanceerde modulatietechniek voor glasvezel met variabele punten.

## Kabel & Verbindingen

**HFC** - Hybrid Fibre Coax: Combinatie van glasvezel en coaxkabel (glasvezel tot straat, coax naar huis).

**FTTH** - Fiber To The Home: Glasvezel tot in de woning.

**DOCSIS** - Data Over Cable Service Interface Specification: Standaard voor datatransmissie over kabelnetwerken.

**CMTS** - Cable Modem Termination System: Systeem dat kabelmodems beheert en verbindt met internet.

**PON** - Passive Optical Network: Glasvezelnetwerk zonder actieve componenten tussen provider en gebruiker.

**MTU** - Maximum Transfer Unit: Maximale grootte van een datapakket (meestal 1500 bytes).

**CRC** - Cyclic Redundancy Check: Foutdetectiemethode door checksum.

**FCS** - Frame Check Sequence: Controleveld aan einde van een frame voor foutdetectie.

## VyOS & Router Configuratie

**CLI** - Command Line Interface: Tekstgebaseerde interface voor apparaatconfiguratie.

**JunOS** - Juniper Operating System: Besturingssysteem van Juniper routers waarop VyOS gebaseerd is.

**CAM** - Constant Awake Mode: Energiemodus waarbij netwerkkaart altijd aan staat.

**ICP** - Internet Cache Protocol: Protocol voor communicatie tussen proxy servers.

## Firewall & Security

**DMZ** - Demilitarized Zone: Geïsoleerd netwerksegment tussen intern netwerk en internet voor servers.

**IDS** - Intrusion Detection System: Systeem dat aanvallen detecteert.

**IPS** - Intrusion Prevention System: Systeem dat aanvallen detecteert en blokkeert.

**SYN** - Synchronize: TCP-vlag om verbinding op te zetten.

**ACK** - Acknowledgement: TCP-vlag om ontvangst te bevestigen.

**FIN** - Finish: TCP-vlag om verbinding af te sluiten.

**RST** - Reset: TCP-vlag om verbinding direct te verbreken.

**IPsec** - IP Security: Protocol suite voor beveiligde IP-communicatie.

**IKE** - Internet Key Exchange: Protocol voor sleuteluitwisseling in IPsec.

**ESP** - Encapsulating Security Payload: IPsec protocol voor encryptie van data.

**AH** - Authentication Header: IPsec protocol voor authenticatie en integriteit.

## ATM & Frame Relay

**ATM** - Asynchronous Transfer Mode: Netwerktechnologie met cellen van vaste lengte (53 bytes).

**PVC** - Permanent Virtual Circuit: Vaste virtuele verbinding tussen twee punten.

**SVC** - Switched Virtual Circuit: Tijdelijke virtuele verbinding opgezet wanneer nodig.

**PCR** - Peak Cell Rate: Maximale snelheid voor piekverkeer in ATM.

**ACR** - Average Cell Rate: Gemiddelde snelheid in ATM verkeer.

**SCR** - Sustainable Cell Rate: Gegarandeerde minimale snelheid in ATM.

**AAL** - ATM Adaptation Layer: Laag die data aanpast voor ATM-transport.

**CAC** - Connection Admission Control: Mechanisme dat controleert of QoS voldaan kan worden.

**LAPF** - Link Access Procedure for Frame Relay: Protocol voor Frame Relay op laag 2.

**DLCI** - Data Link Channel Identifier: Identificatie van virtuele circuits in Frame Relay.

**LMI** - Local Management Interface: Extensie voor Frame Relay met statusberichten.

**CIR** - Committed Information Rate: Gegarandeerde snelheid afgesproken met provider.

## MPLS & Labels

**MPLS** - Multi Protocol Layer Switching: Framework voor snelle doorsturen van verkeer via labels.

**LDP** - Label Distribution Protocol: Protocol voor distributie van MPLS-labels.

## Proxy & Cache

**SOCKS** - Socket Secure: Protocol voor proxy-server die volledig verkeer doorstuurt.

**PSP** - Power Saving Protocol: Energiebesparingsmodus voor apparaten.

**FIFO** - First In First Out: Wachtrijsysteem waarbij oudste item eerst wordt verwerkt.

**CGI** - Common Gateway Interface: Standaard voor dynamische webpagina's.

**ASP** - Active Server Pages: Microsoft technologie voor dynamische webpagina's.

**PHP** - PHP Hypertext Preprocessor: Scripttaal voor server-side webontwikkeling.

## RFID & Draadloze Identificatie

**RFID** - Radio Frequency Identification: Identificatiesysteem via radiogolven met tags.

**NFC** - Near Field Communication: Draadloze technologie voor communicatie over korte afstand.

**UUID** - Universally Unique Identifier: Unieke identificatiecode gebruikt in services.

**LF** - Low Frequency: Frequentieband 125-134 kHz gebruikt voor RFID.

**HF** - High Frequency: Frequentieband 13.56 MHz gebruikt voor RFID.

**UHF** - Ultra High Frequency: Frequentieband 868-955 MHz gebruikt voor RFID.

**MW** - Microwave: Frequentieband 2.45-5.8 GHz gebruikt voor lange-afstand RFID.

## Infrarood & Bluetooth

**IR** - Infrared: Infraroodlicht gebruikt voor draadloze communicatie over korte afstand.

**IrDA** - Infrared Data Association: Standaard voor infrarood datacommunicatie.

**LED** - Light-Emitting Diode: Component die licht uitstraalt voor IR-communicatie.

**OBEX** - Object Exchange: Protocol voor uitwisselen van objecten tussen apparaten.

**LMP** - Link Manager Protocol: Bluetooth protocol voor verbindingsbeheer.

**SDP** - Service Discovery Protocol: Bluetooth protocol om beschikbare diensten te ontdekken.

## SNMP & Netwerk Management

**SNMP** - Simple Network Management Protocol: Protocol voor monitoring en beheer van netwerkapparaten.

**MIB** - Management Information Base: Database met variabelen die via SNMP beheerd kunnen worden.

**OID** - Object Identifier: Unieke reeks nummers die een object in een MIB identificeert.

**ASN.1** - Abstract Syntax Notation One: Standaard taal om datastructuren te definiëren.

**RMON** - Remote Monitoring: Uitbreiding van SNMP voor externe monitoring.

## HTTP/2 & HTTP/3

**QUIC** - Quick UDP Internet Connections: Transportprotocol gebaseerd op UDP voor HTTP/3.

**RTT** - Round Trip Time: Tijd die nodig is voor een pakket om heen en terug te gaan.

**0-RTT** - Zero Round Trip Time: Techniek om data te verzenden zonder handshake vertraging.

**HOL** - Head of Line blocking: Probleem waarbij één geblokkeerde stream alle andere blokkeert.

**SCTP** - Stream Control Transmission Protocol: Transportprotocol dat probeerde TCP te vervangen.

**TFO** - TCP Fast Open: TCP-extensie om data al in SYN-pakket te sturen.
